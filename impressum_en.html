1. Controller

2. Data Protection Officer

A data protection officer has not currently been appointed.

3. General information on data processing

We only process personal data insofar as this is necessary to provide our website, process inquiries, initiate contracts, or fulfill legal obligations.

Personal data is all data with which you can be personally identified or are identifiable.

4. Accessing the website / server log files

This website is hosted via GitHub Pages. When the website is accessed, GitHub automatically collects information in so-called server log files. These are in particular:

  • IP address
  • Date and time of access
  • accessed page/file
  • Referrer URL
  • Browser type and browser version
  • Operating system used

The processing takes place to technically provide the website, ensure stability and security, and detect and prevent misuse.

Legal basis: Art. 6 para. 1 lit. f GDPR
Legitimate interest: technical functionality, IT security, and error analysis
Recipient: GitHub, Inc. (USA)
Storage duration: Usually 7 to 14 days (depending on the host's configuration)

5. Contact by email, phone, or contact form

If you contact us by email, phone, or via the contact form, we process the data you provide to handle your request.

We use the Web3Forms service for the contact form. The data you enter in the contact form (name, company, email, phone, desired service, message) is transmitted directly to Web3Forms and forwarded from there to us.

In particular, the following data can be processed via the contact form visible on the website:

  • Name
  • Company
  • Email address
  • Phone number
  • Desired service
  • Message text

The processing takes place to handle your request, contact you, initiate a contract, and, if applicable, carry out pre-contractual measures.

Legal bases:
• Art. 6 para. 1 lit. b GDPR, insofar as your request is directed towards the conclusion or initiation of a contract
• Art. 6 para. 1 lit. f GDPR, insofar as the processing is necessary for the efficient handling of other requests

Recipient:
• Web3Forms (USA)
• internally responsible employees

Storage duration:
We generally only store requests for as long as necessary for processing. If statutory retention obligations exist or the request is contract-relevant, storage takes place within the framework of legal requirements.

6. Recipients and processors

We use the following external service providers in the context of website operation, who may process personal data on our behalf:

  • GitHub, Inc. (Website hosting)
  • Web3Forms (Contact form processing)

If these service providers process personal data on our behalf, this is done on the basis of a contract for data processing according to Art. 28 GDPR or based on the standard contractual clauses of the EU Commission.

7. Disclosure to third parties and transfer to third countries

Personal data is only passed on to third parties if this is legally permissible, necessary for contract execution, or if we are legally obliged to do so.

When using GitHub Pages and Web3Forms, data is transferred to the USA. Both providers have joined the EU-US Data Privacy Framework, ensuring an adequate level of data protection.

Soweit innerhalb dieser Privacy Policy keine speziellere Speicherdauer genannt wurde, verbleiben personenbezogene Daten bei uns, bis der Zweck der Datenverarbeitung entfällt. Sofern gesetzliche Aufbewahrungspflichten bestehen, erfolgt die Löschung nach Ablauf der jeweiligen Fristen.
